# Como interpretar os mockups

Os boards foram criados a partir das telas reais fornecidas. Eles definem **direção visual**, não dados fictícios a serem codificados.

- Preserve rótulos, dados, permissões e regras do sistema real.
- Use a hierarquia, espaçamento, contraste, miniaturas, chips e agrupamento de ações como referência.
- Não tente reproduzir erros de texto que possam existir em uma imagem gerada.
- O target principal é o board `02-telas-alvo-board.png`.
